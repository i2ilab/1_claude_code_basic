# 学习门禁总清单(c0–c5 + 作业2 + capstone)

> 把每个阶段的验收汇总成一张总表。**每过一关才进下一关。**
> 口诀:**先跑通、再读懂、后讲出——三样齐了才算过。**(验收命令见 `教程_从s3到miniClaudeCode.md` 各阶段"运行验收";可视化对照 `web/index.html`。)

## c0 JSON 协议

- [ ] 跑通:看到 `[执行] → [结果] → [完成]`
- [ ] 🔥 复杂例子过:带引号的内容也能正确写进文件
- [ ] 能讲出:为什么结构化 JSON 能避免 s3 的切割歧义

## c1 工具箱 + 加固

- [ ] `[调用] write_file` / `[调用] read_file` 分开出现
- [ ] 🔥 复杂例子过:TODO.md 只有目标那行被改,其它行没动
- [ ] 能讲出:一个工具"存在"的三件套(函数 / TOOLS 字典 / SYSTEM 公告)
- [ ] 能讲出:为什么真 CC 有专用 Read/Write 而不全用 bash(可控、可审计)

## c2 计划是工具

- [ ] 多步任务先打印一张 ☐ 清单
- [ ] 每完成一步 ☐ 变 ☑,顺序合理
- [ ] 能讲出:todo_write 本质也只是一个普通工具,为什么这就够了

## c3 子智能体

- [ ] `[调用] subagent(...)` 出现
- [ ] 拿回的是**一段总结**,不是几十屏原始代码
- [ ] 能讲出:子 agent 为什么能保持主上下文干净(新开一份 messages)

## c4 上下文压缩

- [ ] 历史超阈值时出现 `[压缩]`(想快点看到:把 LIMIT 临时改小)
- [ ] 压缩后仍记得任务目标、能接着干
- [ ] 能讲出:如果摘要漏了关键细节会发生什么

## c5 权限门(终点)

- [ ] 命中危险词弹出 `[⚠ 权限]` 询问
- [ ] 输入 n 后命令**不执行**,且 AI 收到"用户拒绝了"
- [ ] 能对照真 Claude Code,把五根支柱(工具箱/计划/子 agent/压缩/权限)各自的对应物说全
